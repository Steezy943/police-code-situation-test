Atlanta Police Department Codes Reference

🚨 Response Urgency Levels

  • Code 1Routine call. Respond at convenience without emergency equipment.
  • Code 2Urgent / Non-violent emergency. Urgent response using occasional lights and sirens.
  • Code 3Emergency. True life-safety threat; continuous lights and siren.
  • Code 4Cancel call or no further assistance is needed.
  • Code 7In service / Available.
